# 生产分册（业务用户手册）

> 覆盖模块：`/production`（工单、订单、排程、工艺、报工、发退料、MRP、成品标签）、`/prepress`、`/dcprint`（油墨、配方、流程卡、刀模、网版、工具、追溯）、`/outsource`（委外）、`/material-requisitions`（领料申请）。
> 通用约定见 [00-系统通用说明.md](./00-系统通用说明.md)。

---

## 1. 生产作业全流程

```
销售订单(status 2 已确认)
      │
      ├─ 打样/工艺确认 ──▶ 标准卡、流程卡(/dcprint/process-cards)
      │
      ▼
生成生产工单(/production/workorder/new) ──自动写回销售订单 status=3 部分发货
      │
      ▼
生产排程(/production/schedule)  ── 自动排程 / 产能分析 / 冲突检测
      │
      ▼
工序报工(/production/process、/production/report 扫码报工)
      │
      ▼
领料 / 退料(/production/material-issue、material-return、/material-requisitions)
      │
      ▼
完工入库 ──▶ 销售订单 status=4 已完成
```

**关键点**：工单是生产的入口，一切报工、领料、入库都挂在工单上；工单状态不是人工随便改的，是由「确认排程 / 报工 / 完工」等业务动作推进的。

## 2. 生产工单 `/production/workorder`

列表列：工单号 `work_order_no`、产品资讯 `product_name`、客户 `customer_name`、数量、状态、优先级 `priority`、计划开始 `plan_start_date` / 计划完成 `plan_end_date`。展开行显示明细：行号 `line_no`、物料编码、物料名称、数量、单位、状态。

### 2.1 状态机（唯一真相源 `src/lib/constants.ts` 的 `WorkOrderStatus`）

| 值 | 含义 | 常见推进来源 |
|----|------|--------------|
| `pending` | 待处理 | 新建默认 |
| `confirmed` | 已确认（已排程/已开工） | 排程确认、发料确认 |
| `producing` | 生产中 | 报工 |
| `completed` | 已完成 | 完工入库 |
| `cancelled` | 已取消 | 取消工单 |

> 只有这 5 个规范值。库里历史遗留的 `'1'`、`'migrated'`、`'scheduled'`、`'in_progress'` 已被 `normalizeWorkOrderStatus()` 归一，**不要再手工写这些值**。

### 2.2 操作与接口

| 操作 | 入口 | 接口 |
|------|------|------|
| 新增 | `/production/workorder/new`：选销售订单 → 展开 BOM → 生成工单 | `POST /api/workorders` |
| 编辑 | 行内 | `PUT /api/workorders?id=` |
| 删除 / 批量删除 | 行内 / 勾选 | `DELETE /api/workorders?id=` |
| 列印工单 | 行内 | 前端打印 |
| 工序推进 | 行内 | `/api/production/work-orders/{workOrderNo}/process-step` |
| 色序 / 多色 | — | `/api/production/work-order/color-seq`、`/create-multi-color` |
| 查看 BOM | 新增页 | `/api/orders/bom` |

**新增约束**：若所选销售订单「没有可生成的明细」，会提示无法生成工单。

## 4. 生产排程 `/production/schedule`

三视图：日历 / 甘特 / 列表；含产能分析与冲突检测。

| 操作 | 接口 |
|------|------|
| 新增 / 编辑排程 | `/api/production/schedule` |

## 5. 工艺管理与报工

### 5.1 `/production/process` 工艺管理（工序报工）
列：流程卡号、产品资讯、客户、数量、制程流程、进度、状态。
接口 `/api/production/process`、`/api/production/process/stats`；操作：报工、确认报工、填写报工备注。

### 5.2 `/production/report` 生产报工
主功能：扫码 / 手动报工（员工卡、工单条码、设备条码），支持完成报工与历史查询。
接口 `/api/production/work-report`。
字段：报工编号、工单号、工序名称、操作人、设备、计划产量、完成数量、合格数、报废数、效率、工时。

> 报工是**完成数量与合格数的唯一入口**，车间的完工数（`prod_work_order.completed_qty`）以报工数据回写为准。

## 6. 领料 / 退料

| 页面 | 用途 | 接口 | 关键字段 |
|------|------|------|----------|
| `/production/material-issue` | 生产发料 | `/api/production/material-issue` | 领料编号 `issue_no`、工单号、仓库、领料日期 `issue_date`、领料类型、操作人、状态 |
| `/production/material-return` | 生产退料 | `/api/production/material-return` | 退货单号、工单号、仓库、退料日期、操作人、状态 |
| `/material-requisitions` | 领料申请（独立菜单） | `/api/material-requisitions`、`/{id}/issue` | 领料单号、工单号、类型、状态（待出库 / 已出库）、数量、申请人、申请时间 |

领料申请的操作链：提交 → 审核 → **自动生成领料单** → 确认出库 → 扫码出库。

> ⚠️ 领料涉及批次扣减（FIFO），规则见 [03-仓储分册.md](./03-仓储分册.md) §6。

## 7. MRP 运算 `/production/mrp`

操作：MRP 运算、BOM 展开、**自动生成采购申请**。
净需求表列：物料编码、物料名称、毛需求、库存量、已分配、在途、安全库存、净需求、提前期(天)、建议下单日期、短缺预警。
另有时间桶明细（毛需求 / 计划接收 / 库存量 / 净需求 / 计划下达），分桶粒度：按天 / 按周 / 按月。

参与运算的工单状态：`pending / confirmed / producing`（`WORK_ORDER_STATUSES_OPEN`）。

> ⚠️ **已知限制**：MRP 依赖 `explodeBOM`，而当前 BOM 明细与 `inv_material` 的关联存在双轨问题（部分物料走 `mdm_product`/`inv_material` 两套 id 空间），MRP 结果可能与实际主数据不一致。**MRP 结果请人工复核后再用于下单**。

## 10. 委外加工 `/outsource`

| 页面 | 用途 | 接口 |
|------|------|------|
| `/outsource/order` | 委外订单 | `/api/outsource/order` |
| `/outsource/issue` | 委外发料（过账后扣减库存） | `/api/outsource/issue` |
| `/outsource/receive` | 委外收货（过账后增加库存） | `/api/outsource/receive` |
| `/outsource/settlement` | 委外结算（确认结算、付款确认） | `/api/outsource/settlement` |

委外订单字段：订单号、供应商名称、产品、委外类型、工序、计划产量、已发数量、已收数量、合格数量、交货日期、状态。

状态流转：`pendingIssue 待发料 → issued 已发料 → partiallyReceived 部分收货 → completed 已完成 → settled 已结算`，取消为 `已取消`。
发料单字段：发料单号、订单号、仓库、发料日期、明细、操作人、状态。收货字段：收货单号、入库仓库、收货日期、收货数量、合格数量、不良数量、质检状态。

**过账提示（系统弹窗原文）**
- 发料：*「确认过账发料？过账后将扣减库存。」*
- 收货：*「过账后将增加库存并更新委外订单。」*

> 发料/收货的过账会**真实改变库存**，点确认前请核对数量与仓库。

## 11. 生产域常见问答

| 问题 | 说明 |
|------|------|
| 销售订单自己变成「部分发货」 | 生成工单时自动写，正常 |
| 工单状态可以手工改吗 | 不建议；状态由排程/报工/完工等业务动作推进，手工改会与数量口径脱节 |
| 工单完工后销售订单变「已完成」 | 正常：该订单下所有工单完工后自动写 |
| 领料后批次不够了 | FIFO 会按「余料 > 开封 > 临期 > 入库日期」挑选批次；先点「FIFO 分配」看预览 |
| 想指定用某个批次领料 | 在出库/领料明细里直接填批次号，走指定批次出库，不走 FIFO |
| MRP 算出来的净需求量不对 | 已知限制：BOM 与主数据双轨导致，结果需人工复核 |
| 油墨配方能改吗 | 可以改，但改的是「新版本」；已启用的需要「停用再启用新版本」 |
| 委外发料点错了 | 别手工改库存，走「反审核/取消」后再重发 |
| 报工数据能删吗 | 需在「历史报工记录」里删除，删除后完工数会同步回退 |
