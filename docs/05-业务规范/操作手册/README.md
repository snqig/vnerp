## 使用约定

- 手册只记**当前版本行为**；业务功能变更时先改手册再发版。
- 已确认的缺陷与未打通的断点，一律以 ⚠️ 显式标注，并给出变通做法；**不写「应该可以这样」的推测**。
- 手册与代码/数据库实际行为冲突时，以代码与库为准，并在手册中标注差异。
