# ERP 系统数据字典

> **版本**：v1.0
> **更新日期**：2026-09-26
> **说明**：数据库核心表和字段说明

---

## 一、仓储库存模块

### 1.1 inv_warehouse（仓库表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| code | varchar(50) | 仓库编码 |
| name | varchar(100) | 仓库名称 |
| type | tinyint | 仓库类型：1=原材料仓, 2=半成品仓, 3=成品仓, 4=辅料仓 |
| status | tinyint | 状态：0=禁用, 1=启用 |
| deleted | tinyint | 软删除：0=正常, 1=已删除 |

### 1.2 inv_material（物料表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| code | varchar(50) | 物料编码 |
| name | varchar(100) | 物料名称 |
| specification | varchar(200) | 规格 |
| unit | varchar(20) | 单位 |
| material_type | tinyint | 类型：1=原料, 2=半成品, 3=成品, 4=辅料 |
| safety_stock | decimal(10,2) | 安全库存 |

### 1.3 inv_inventory（库存汇总表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| material_id | int | 物料ID |
| warehouse_id | int | 仓库ID |
| quantity | decimal(10,2) | 总数量 |
| available_qty | decimal(10,2) | 可用数量 |
| locked_qty | decimal(10,2) | 锁定数量 |
| frozen_qty | decimal(10,2) | 冻结数量 |
| unit_cost | decimal(10,4) | 单位成本 |
| total_cost | decimal(12,2) | 总成本 |

### 1.4 inv_inventory_batch（库存批次表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| batch_no | varchar(50) | 批次号 |
| material_id | int | 物料ID |
| warehouse_id | int | 仓库ID |
| quantity | decimal(10,2) | 批次数量 |
| available_qty | decimal(10,2) | 可用数量 |
| unit_price | decimal(10,4) | 批次单价 |
| inbound_time | datetime | 入库时间 |
| expire_date | date | 有效期至 |
| status | tinyint | 状态：0=正常, 1=冻结, 2=过期 |

### 1.5 inv_inbound_order（入库单）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| inbound_no | varchar(50) | 入库单号 |
| order_type | varchar(20) | 类型：purchase=采购, production=生产, return=退货 |
| supplier_id | int | 供应商ID |
| warehouse_id | int | 仓库ID |
| status | varchar(20) | 状态：pending=待审核, approved=已审核, completed=已完成 |
| total_qty | decimal(10,2) | 总数量 |

### 1.6 inv_outbound_order（出库单）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| outbound_no | varchar(50) | 出库单号 |
| outbound_type | varchar(20) | 类型：sales=销售, production=领料, transfer=调拨 |
| customer_id | int | 客户ID |
| warehouse_id | int | 仓库ID |
| status | varchar(20) | 状态：pending=待出库, completed=已完成 |

## 二、生产模块

### 2.1 prod_work_order（生产工单）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| work_order_no | varchar(50) | 工单号 |
| product_id | int | 产品ID |
| qty | decimal(10,2) | 计划数量 |
| completed_qty | decimal(10,2) | 完工数量 |
| status | varchar(20) | 状态：draft=草稿, scheduled=已排产, producing=生产中, completed=已完工 |
| sales_order_id | int | 关联销售订单ID |

## 三、销售模块

### 3.1 sal_order（销售订单）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| order_no | varchar(50) | 订单号 |
| customer_id | int | 客户ID |

| status | varchar(20) | 状态：draft=草稿, confirmed=已确认, shipped=已发货, completed=已完成, cancelled=已取消 |

## 四、系统模块

### 4.1 sys_user（用户表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| username | varchar(50) | 用户名 |
| name | varchar(50) | 姓名 |
| password_hash | varchar(255) | 密码哈希 |
| role_id | int | 角色ID |
| department_id | int | 部门ID |
| status | tinyint | 状态：0=禁用, 1=启用 |

### 4.2 sys_role（角色表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| code | varchar(50) | 角色编码 |
| name | varchar(50) | 角色名称 |

### 4.3 sys_menu（菜单表）

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| parent_id | int | 父菜单ID |
| name | varchar(50) | 菜单名称 |
| path | varchar(200) | 路由路径 |
| code | varchar(100) | 菜单编码（国际化 key） |
| sort | int | 排序 |
