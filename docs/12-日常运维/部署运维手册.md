## 2. 部署步骤

### 2.1 开发环境部署

```bash
# 1. 克隆代码
git clone https://github.com/snqig/vnerp.git
cd vnerp

# 2. 安装依赖
npm install

# 3. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local 填入数据库配置

# 4. 启动开发服务器
npm run dev

# 5. 访问 http://127.0.0.1:5000
```

### 2.2 生产环境部署

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 安装依赖
npm install --production

# 3. 构建
npm run build

# 4. 启动服务
npm start
```

## 5. 故障排查

### 5.1 页面打不开

**排查步骤**：
1. 检查服务是否运行：`pm2 list` 或 `ps aux | grep node`
2. 检查端口是否监听：`netstat -tlnp | grep 5000`
3. 查看错误日志：`pm2 logs`

### 5.2 数据库连接失败

**排查步骤**：
1. 检查 MySQL 是否运行：`systemctl status mysql`
2. 检查连接配置：`.env.local` 中的数据库地址、用户名、密码
3. 测试连接：`mysql -u root -p -h 127.0.0.1`

### 5.3 数据不一致

**排查步骤**：
1. 检查库存汇总表和批次表是否一致
2. 调用库存重算 API：`POST /api/warehouse/inventory/recompute`
3. 查看库存流水：`SELECT * FROM inv_inventory_transaction ORDER BY id DESC LIMIT 100`
