## 四、架构与业务评价

### 4.1 亮点（值得肯定）

1. **DDD 分层骨架完整且方向正确**：domain（165 文件，聚合根/值对象/事件/仓储接口）→ application（应用服务+事件处理器）→ infrastructure（MySQL 仓储/事件总线/缓存）→ presentation（Thin Controller），依赖倒置成立；equipment/hr 已开始迁移。
2. **事件驱动一致性设施扎实**：领域事件 + Outbox + IdempotencyGuard + Saga 编排器 + 幂等标记，EventBus 生产强制 DB 模式——**设施完备，只差补偿 handler 填业务回滚（F-003）**。
3. **库存核心链路正确**：入库事件 `inbound.approved → InventorySyncHandler` UPSERT 累加 + `recomputeInventorySummary`；出库 FIFO 预留/确认乐观锁（`version`）+ 批次效期排序 + 冻结/过期排除——符号与重算无漂移（tasks.md 专项结论 + 本次代码复核一致）。
4. **多币种与国际化**：CurrencySnapshot 不可变值对象、汇率历史、四语言 next-intl、ESLint 硬编码检测——Phase 2b 完成度较高。
5. **安全基线良好**：JWT+刷新令牌+限流+权限全覆盖+上传白名单+调试路由下线+`.env` 不入库。
6. **工程治理**：迁移脚本 100 个且幂等、`guard-drizzle-kit` 防 FK-drop 卡点、i18n key 校验、lint-gate baseline、Git 工作流规范、监控（prometheus/grafana/alertmanager）全套。
