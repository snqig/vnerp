## 一、项目画像

- **定位**：丝网印刷 / 包装印刷行业生产经营一体化管理系统
- **技术栈**：Next.js 16.1.1（App Router + Turbopack）· React 19.2.3 · TS 5 严格模式 · Drizzle ORM 0.45 · MySQL 8.0 · Redis（Streams 事件总线 + 缓存）· pnpm 9

**核心差距（相对商业 ERP 的竞争短板）**：
1. **专业报价引擎缺失** —— 商业印刷 ERP 的第一卖点（报价快、准），vnerp 仅有样品卡报价；
2. **智能排产未接入** —— 算法已写好但无 API 调用（`production-scheduling.ts` 零引用），生产-产能-交期闭环缺一环；
3. **成本分摊精度不足** —— 制造费用按比例估算，不满足"按机台/按工单精确归集"；
4. **客户在线门户缺失** —— B2B 印刷客户协作（在线下单/进度/审批）是差异化功能；
5. **设备数据采集（JDF/JMF）** —— 商业系统与印刷机联网，vnerp 为人工报工。

**vnerp 相对优势**：多币种 + 四语 i18n（出口印刷企业刚需）、二维码批次全流程追溯、印前专业域深度、HR 计件薪酬引擎——这些是**多数国产印刷 ERP 不具备的**。

## 八、架构亮点（治理时勿破坏）

1. **DDD 分层执行到位**：领域层 0 框架依赖（本次扫描实证）；18 个子域，依赖方向严格自上而下。

5. **并发控制成熟**：乐观锁 version + `transactionWithRetry` 指数退避 + UPSERT 原子写。
6. **迁移治理规范**：98 个编号迁移 + `INFORMATION_SCHEMA` 守卫 + 幂等；guard-drizzle-kit 防 DROP FK 护栏是**教科书级**做法。
7. **印刷行业特色深度**：刀模/网版/油墨生命周期、二维码全流程追溯、HR 计件引擎、多币种+四语——多数国产印刷 ERP 不具备。
