# 采购订单全页表单设计

## 背景

采购订单模块当前使用弹窗内嵌表单创建订单。后端已完成三步改造（仓储层 `purchaseOrderDraftWrite.ts`、服务层 `updateOrder`、路由层 `PUT action: 'update'`），现在需要将前端重构为全页表单模式，支持新建和编辑。

## 文件变更

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/app/[locale]/purchase/orders/new/page.tsx` | 新建 | 全页新建表单 |
| `src/app/[locale]/purchase/orders/[id]/edit/page.tsx` | 新建 | 全页编辑表单 |
| `src/app/[locale]/purchase/orders/page.tsx` | 修改 | 移除创建弹窗，新增分页控件，编辑跳转 |
| `src/app/[locale]/purchase/orders/[id]/page.tsx` | 修改 | 详情页添加编辑按钮 |

## 新建 vs 编辑差异

| 项目 | 新建页 | 编辑页 |
|------|--------|--------|
| 币种 | 可选（默认 CNY） | **只读**，显示原值 |
| API | `POST /api/purchase/orders` | `PUT /api/purchase/orders` + `action: 'update'` |
| currency 字段 | 包含 | **不包含**（后端强制沿用库中值） |
| 提交按钮 | 保存草稿 / 提交审批 | 保存草稿 / 提交审批 |

## 物料行交互

- 每行有一个「选择物料」按钮 → 打开 `MaterialPicker` 弹窗
- 选择后自动填充：编码、名称、规格、单位、单价（取 `purchase_price`）
- 数量和金额联动：数量 × 单价 = 金额
- 支持添加/删除行，至少保留一行
- 提交时过滤空行（`material_code` 为空且 `quantity <= 0` 的行）

## 列表页改动

### 分页
- `pageSize` 从 20 → 50
- 新增分页条：首页 / 上一页 / 页码 / 下一页 / 末页 / 跳转输入框

### 创建弹窗移除
- 删除第 827-1000 行的整个 `Dialog` 区块
- 「新建采购订单」按钮 → `router.push('/purchase/orders/new')`

### 编辑跳转
- 表格行操作菜单新增「编辑」项（仅 `status < 30` 时显示）
- 点击 → `router.push('/purchase/orders/${order.id}/edit')`

## 详情页改动
- 在操作菜单添加「编辑」按钮（仅 `status < 30` 时显示）
- 点击 → `router.push('/purchase/orders/${order.id}/edit')`

## 翻译键
现有 `zh-CN.json` 已包含 `edit`、`create`、`cancel`、`draft`、`pending` 等键，无需新增。

## 技术约束

1. **币种不可变**：编辑页 `CurrencySelect` 设 `disabled`，提交时不带 `currency` 字段
2. **仅草稿可编辑**：`status < 30`（即 10 草稿 / 20 待审批）才显示编辑入口
3. **物料分类校验**：后端 `checkMaterialsCategorized` 在 PUT 时校验，前端无需额外处理
4. **并发控制**：后端 `updateDraft` 使用 `SELECT ... FOR UPDATE`，前端无需处理
