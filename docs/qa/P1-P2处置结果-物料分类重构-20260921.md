## 1. 背景与口径

用户要求的「原材料清单」在 DB 中**并不存在**：`inv_material` 共 4791 行，其中 3267 行 `category_id=159` 为**成品**（finished goods，如 `SZ12200090`、`P-0169-CDR`），19 行挂在历史遗留桶，真实原材料主数据仅 26 行 `MATxxx`。用户给出的示例编码（0.033KB / 3M7533 / MTL-75C / KAPTON）只出现在 vnERP 种子 SQL，不在线上库。

关键口径澄清：
- `material_type`（tinyint）是**生命周期类**：1=原材料 / 2=成品 / 3=备品 / 4=辅助 / 5=其他 —— 与用途无关。
- 用户的 12 类「用途」应挂在 **`category_id`**，导入原料行 `material_type` 恒为 1。
- 旧分类仅 169 行且粗粒度（`RAW/AUX/PKG/SPL` 一级 + `CAT辅料` 子树挂 100+ 油墨子类型），与 12 类方案不匹配 → 按用户授权「12 类重构替换旧」全量重分类。
